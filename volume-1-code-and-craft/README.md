# Volume 1, Code and Craft

The first volume of *SEO for Engineers*. This volume covers the surfaces
engineers build. How search engines crawl, render, and index the web. How
rendering strategy determines what Googlebot actually sees. How Core Web
Vitals behave as architectural constraints. How URLs, HTTP semantics,
sitemaps, robots.txt, and crawl budget shape what can be indexed.
